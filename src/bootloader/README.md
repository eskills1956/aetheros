# Aether OS Bootloader

This directory contains bootloader configuration and customizations.

## Components:

- **U-Boot Configuration** - Bootloader for ARM devices
- **GRUB Configuration** - Bootloader for x86_64 devices
- **Boot Scripts** - Custom boot scripts
- **Splash Screen** - Boot animation/logo

## Status

Currently using device-specific bootloaders. Custom configuration will be added as needed.
